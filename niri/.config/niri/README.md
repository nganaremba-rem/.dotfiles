# 🧭 niri config

Modular [niri](https://niri-wm.github.io/niri/) config. `config.kdl` only wires the modules
together, in an order that matters (later values win).

```
niri/
├── config.kdl              🧭 entry point — includes only
├── settings/
│   ├── apps.kdl            🎯 default apps ($NIRI_TERMINAL, $NIRI_BROWSER, …)
│   ├── input.kdl           ⌨️ keyboard repeat, touchpad, focus-follows-mouse
│   ├── layout.kdl          📐 column widths, border, shadow, overview
│   ├── animations.kdl      🎞️ springs and curves
│   ├── misc.kdl            ⚙️ screenshot path, CSD, hot corners, env
│   └── startup.kdl         🚀 spawn-at-startup
├── rules/
│   ├── windows.kdl         🪟 per-app rules (order matters)
│   └── layers.kdl          🧱 bars / launchers (blur, backdrop)
├── binds/
│   ├── apps.kdl            🚀 terminals, editor, launchers, DMS, tools
│   ├── web-apps.kdl        🌐 sites as app windows
│   ├── windows.kdl         🪟 focus / move / resize / float / tabs
│   ├── workspaces.kdl      🗂️ workspaces + monitors
│   ├── media.kdl           🔊 volume, mic, playback, brightness
│   ├── screenshots.kdl     📸 screenshots + OCR
│   ├── session.kdl         🔒 lock, power, quit, escape hatch
│   └── alt-tab.kdl         🔁 Alt+Tab switcher
├── dms/                    🎨 generated by DankMaterialShell — don't edit
└── archive/                🗄️ old modules nothing includes
```

## 🎯 Change a default app

Edit **one line** in `settings/apps.kdl`; every keybind follows on save:

| Variable | Used by |
|---|---|
| `NIRI_TERMINAL` | Mod+Return, scratchpad, btop, RemTop |
| `NIRI_TERMINAL_RUN` | anything run *inside* a terminal (`-e`): tmux, nvim, todo, wiremix, Wi-Fi, Claude Code |
| `NIRI_EDITOR` | Mod+N, Mod+Shift+N (edit this config) |
| `NIRI_BROWSER` | Mod+B and every web app in `binds/web-apps.kdl` |
| `NIRI_VIM_BROWSER` | Mod+Alt+B |
| `NIRI_FILE_MANAGER` | Mod+E |
| `NIRI_LAUNCHER` | Mod+Space |

niri has no config variables; these are environment variables niri passes to what it
spawns, read with `spawn-sh "$NIRI_…"`. They're `NIRI_`-prefixed so they don't change
`xdg-open`/`$BROWSER` behaviour for other apps.

## ✍️ Everyday edits

- **Add a keybind:** put it in the matching `binds/*.kdl`. Add
  `hotkey-overlay-title="🔤 Name"` to list it in the overlay (Mod+Shift+/).
- **Add a window rule:** `rules/windows.kdl`. Find app ids with `niri msg windows`.
- **Check before saving:** `niri validate`. niri reloads on save, and keeps the old
  config if the new one fails to parse (failure notifications are off in `settings/misc.kdl`).
- **Monitors:** use DMS settings — `dms/outputs.kdl` is the single source of truth.
